# MGT4017 — BeautyLoop

Responsive BeautyLoop skincare website concept, based on the supplied visual wireframe.

## Website files
- `index.html` — website structure and content
- `styles.css` — styling and responsive layouts
- `script.js` — demo bag counter, plan buttons and mobile menu
- `assets/` — product and refill photographs cropped from the supplied BeautyLoop design reference

## Preview locally
Open `index.html` in a browser. No installation or build process is needed.

## Publish with GitHub Pages
1. Create a GitHub repository named `MGT4017`.
2. Upload all files and the `assets` folder to the repository root (do not upload only the ZIP).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment and copy the published website URL.

## Important
This is a front-end student project/demo. The bag and subscription buttons show demonstration messages only; no real checkout, payments, customer accounts or order processing are connected. Product descriptions, ingredient information, reviews and prices are illustrative and should be verified before any commercial use.
